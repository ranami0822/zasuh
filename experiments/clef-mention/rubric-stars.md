# 星のラベル付けの規約（案 v0.1）

状態: **要決定の5点は、すべて決まった（2026-11-20、ユーザー）。** ラベル付けの前に、ユーザーが、全体を、もう一度確認する。第7弾（`README.md`）で使う。

星は、作品の良し悪しではなく、**本文が、その観点について、どのくらい強く肯定・否定しているか**を表す。
観点、言及の有無、観点の分け方は、`rubric.md`（v2）のまま。「言及なし」の観点には、星を付けない。

## 付けるもの

各（レビュー、観点）に、2つ。

1. **星**: 1〜5。または「言及なし」「判断不能」。
2. **向き**: 肯定・否定・混在・言及なし・判断不能（`rubric.md` v2 のとおり）。

向きと星を別に付けるのは、星3が「混在」（良い点と悪い点がある）と「ふつう」（どちらでもない）のどちらにも読めるため。

## 星の基準（ユーザーの決定を反映）

| 星 | 基準 |
| --- | --- |
| 5 | **具体的な根拠があり、強い言い方**で書かれている（根拠は1点でよい）。「最強！」だけは、根拠がないので数えない |
| 4 | 具体的な良い点が書かれている（1点でもよい。強い言い方でなくてもよい）。**または、良い点が多く、悪い点が少しだけの混在**（向きは「混在」） |
| 3 | 良い点と悪い点が、同じ程度の混在。または、良くも悪くもない、と具体的に書かれている |
| 2 | 具体的な悪い点・不満が書かれている。**または、悪い点が多く、良い点が少しだけの混在**（向きは「混在」） |
| 1 | **具体的な悪い点があり、強い言い方**で書かれている（1点でよい） |

- 星1は、星5の対称として私が置いた（ユーザーは、星5の条件だけを答えた）。違えば直す。
- **深さ（具体的な点の数、文章の長さ）は、星に入れない**。星は、強さだけを表す。深く書いたレビューと端的なレビューの違いは、星には出ない（ユーザーが、「複数」の条件を外した結果）。
- 「どれだけ多いか」の判断は、あいまいで、ばらつく。それを含めて、ラベル付け者どうしの一致率を、モデルの上限の目安にする。

## 決めたこと（2026-11-20、ユーザー）

1. **星5の条件**: 具体的な根拠があり、強い言い方で書かれていること（上の表）。最初は「複数の具体的な点」だったが、観点ごとに数えると、例の文が星5にならないため、ユーザーが「複数でなくてよい。根拠があって、強い言葉なら」に直した。
2. **混在**: 多いほうに寄せる（星4または2）。釣り合っていれば星3。
3. **事実だけの記述**（「クリアまで12時間」）: 判断不能のまま。

4. **理由のない賛辞**（「神ゲー」「クソゲー」）: **今回の実験は、数えない**（v2 のまま「言及なし」）。

## 別の課題（今回の実験の外）

- ユーザーの懸念: 理由を要求すると、「書くのにペンが重くなる」（投稿の壁になる）可能性がある。観点のない賛辞を、「総合の星」として弱い評価で数える案は、別の実験として検討する。2026-11-15 までの方針（理由のない評価は数えない）を変えることになるので、決める前に、ユーザーの確認が要る。

## 例（架空。決まったら増やす）

- 「戦闘が爽快」→ gameplay: 星4、肯定。
- 「ロードが長い」→ comfort: 星2、否定。
- 「BGMはいいが、曲が途切れるのが残念」→ music: 星3、混在（釣り合っている）。
- 「戦闘は爽快で、敵の種類も多い。ただ、ボス戦だけは理不尽」→ gameplay: 星4、混在（良い点が多く、悪い点が少しだけ）。
