# 星のラベル付けの規約（案 v0）

状態: **案。「要決定」の項目を、ユーザーが決めるまで、ラベルを付けない。** 第7弾（`README.md`）で使う。

星は、作品の良し悪しではなく、**本文が、その観点について、どのくらい強く肯定・否定しているか**を表す。
観点、言及の有無、観点の分け方は、`rubric.md`（v2）のまま。「言及なし」の観点には、星を付けない。

## 付けるもの

各（レビュー、観点）に、2つ。

1. **星**: 1〜5。または「言及なし」「判断不能」。
2. **向き**: 肯定・否定・混在・言及なし・判断不能（`rubric.md` v2 のとおり）。

向きと星を別に付けるのは、星3が「混在」（良い点と悪い点がある）と「ふつう」（どちらでもない）のどちらにも読めるため。

## 星の基準（案）

| 星 | 基準 |
| --- | --- |
| 5 | 大きく肯定。具体的な良い点が、強い言い方、または複数の点で書かれている |
| 4 | 肯定。具体的な良い点が書かれている |
| 3 | 良い点と悪い点が、同じ程度。または、良くも悪くもない、と具体的に書かれている |
| 2 | 否定。具体的な悪い点・不満が書かれている |
| 1 | 大きく否定。強い言い方、または複数の点、「プレイにならない」など |

## 要決定（ユーザー）

1. **4と5の境。** 「強い言い方」（「圧倒的」「今までで一番」など）か、「複数の点を挙げている」か、両方か。
2. **良い点が多く、悪い点が少しだけの「混在」。** 星3にするか、4にするか。向きは「混在」。
3. **事実だけの記述**（「クリアまで12時間」）。`rubric.md` v2 では「判断不能」。そのままでよいか。
4. **深く書いたレビューと、端的なレビュー。** 同じ「肯定」なら、同じ星4でよいか。深さを星に反映させるか（反映させるなら、基準に書く）。
5. **理由のない賛辞**（「神ゲー」）。v2 では「言及なし」。そのままでよいか。

## 例（架空。決まったら増やす）

- 「戦闘が爽快で、敵の動きも多彩」→ gameplay: 星4、肯定。
- 「戦闘が爽快で、敵の動きも多彩で、何周しても飽きない。今までで一番」→ gameplay: 星5、肯定（要決定1による）。
- 「ロードが長い」→ comfort: 星2、否定。
- 「ロードが長く、よく落ちる。プレイにならない」→ comfort: 星1、否定。
- 「BGMはいいが、曲が途切れるのが残念」→ music: 星3、混在。
