## 1. 方向（決定、2026-11-15）【今回】

- 「乳首」。バカなこと。部品は乳首の隠喩で、ユーザーが触ることは、アプリの乳首をいじること。
- **色は、乳首そのもの**（肌、輪、赤みのカード）。**ピンクは入れない**（当初の「ピンクがドミナント」は、この提案パレットで置き換わった。ピンクがないこと自体が、本人の意図）。鮮やかなピンクのアクセントは、コンセプトに合わないと判断して見送り（私の意見。本人も迷っていた）。
- ほかの色は灰色のベース（少し前の Apple HIG の灰色）。アクセントは**ミント**（意図的な変更。当初のアーモンドグリーンから）。
- 面を中心にする。線は使わない。グラデーション、粒状感（grain）、色つきの影は、場合に応じて使う。
- 説明しない。感性デザイン。
- 将来（今ではない）: 水色（ミント）の細かいマスクで、下着の模様を表現する。

使い方の制約（コントラスト比で確認）:

- 文字 `#17181A` は、全ての面の上で 5.6 以上。
- 補足の文字 `#4A4B4F` は、背景、面、輪、小要素、Highlight の上では 5.3 以上。カード（赤み）の上では 2.8、カード（標準）の上では 4.0、押下の上では 3.5 で足りないので、カードの上は主役の文字色を使う。
- 主役の灰色 `#9A9BA0` は、どの面の上でも 2.6 以下で、文字には使わない（装飾用）。
- 白い文字は、カードの上で 2.2〜3.2 で足りないので使わない。
- 面、輪、小要素の差は小さい（比で 1.07〜1.14）。線を使わないので、影で分ける。

## 4. 確認したこと

- UnifontEX（`@fontsource/unifontex` 5.3.0、OFL-1.1）は、1ファイルで日本語（ひらがな、カタカナ、漢字）を描画できた。Chromium で、16px・32px・48px のとき、ドットがくっきり出ることを画面で確認した（`pnn/design/preview.html`）。
- 元の woff2 は約 2 MB の1ファイル。`pnn/scripts/build-font.py` で、JIS X 0208 の水準を基準に4つの塊へ分けた（`pnn/fonts/`）。`base`（英数字、かな、記号）13 KB、`kanji1`（第1水準）139 KB、`kanji2`（残りの JIS X 0208）178 KB、`rest`（それ以外のすべて）1,571 KB。`unicode-range` で、ページに出た文字が入る塊だけを読み込む。
- ブラウザで確認（Chromium）: かなと第1水準だけの文は `base` + `kanji1`、第2水準の漢字が混じると `kanji2` が加わり、範囲外の文字（龘、𠮷）では `rest` が加わる。範囲外の文字も、オンラインならドットの見た目で出る（オフラインでキャッシュ前なら、システムのフォントになる）。
- CDN（jsDelivr）にも同じファイルがあるが、自前で配信する。ブラウザのキャッシュはサイトごとに分かれるので共有の利点がなく、利用者の IP が第三者に渡るため。
- 削ったフォントの全文字の見た目は、確認していない（上の確認は、読み込まれる塊と、代表的な文字のみ）。
- **コントラスト（WCAG の比）**: 文字 `#1c1c1e` はピンク `#ff6fa8` の上で 6.6、肌色の上で 14.1。**白い文字はピンクの上で 2.6 で足りない**ので、ピンクの上の文字は暗い灰を使う。**`#7f9c67`（濃いアーモンド）は肌色の上で 2.5 で、文字には使えない**（強調の線や塗りには使える）。

## 5. 注意・未決

- 本文のフォントサイズは 16 の倍数（16 / 32 / 48）が前提と見ている（ピクセルフォントのため。貼り付けられた別のプロジェクトの記録と、16/32/48 でだけ確認した画面からの推測。14px などは未確認）。
- 長い小説を UnifontEX で読めるか（行間、疲れやすさ）は、未確認。小説の場では、別の書体にする選択肢を残す。
- ui-sdk は 0.1.0-beta.3（npm の `@ui-sdk/svelte`）。Svelte での導入は、まだ試していない。
- 貼り付けられた記録にあった Panda CSS（トークンと 8px グリッドの検出）は、別のプロジェクトの構成で、ここでは採用を決めていない。
- 粒状感（grain）は、画面上ではごく薄い。必要なら濃さを上げる。
- 灰色の使い道: 現状は文字と中立の面だけ。ライトでは肌色が面の大半を占める。灰色をどこまで広げるかは、本人の判断。
- 触ったときの「乳首」の動き（押す、弾む、など）は未設計。
- 絵文字は UnifontEX に入っている（U+1F300〜1FAFF に 1,584 字。新しいもの、たとえば U+1FA72 は入っていない）。ただし、今の分け方では、❤（U+2764）など記号類も、1.5 MB の `rest` に入っている。いいねのハートなどを出すだけで `rest` を読み込むのは重いので、記号類と絵文字を別の小さな塊に分ける予定。
